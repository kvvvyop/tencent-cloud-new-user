## “新用户”怎么算：买过一台就不算

腾讯云的活动资格看的是“产品首单”，跟账号注册时间无关。只要账号从没购买过轻量应用服务器（Lighthouse），就算产品首单，能买秒杀和首单专区；买过哪怕1个月，38元、68元这些价格就与你无关了。前提是账号已完成实名认证，个人或企业都行。

有两个细节经常被忽略：

- 轻量应用服务器和云服务器CVM算两个独立产品，首单资格分开计算。买过CVM的账号，仍然可以享受轻量的首单优惠，反过来也一样。

同价续费专区新老同享，老用户也能买，只是每个配置限新购1次、续费1次。

如果你手上有多个互不相关的业务，用另一个手机号注册新账号，能各自享受一次首单价。普通个人用户没必要为了几十块钱多养一个账号，业务确实分开的情况可以这么操作。

2核2G够跑个人博客、静态站和轻量API；4核4G是这轮促销里性价比最高的档位，Docker、小游戏服、几个小站并排跑都没问题；2核4G/6M的卖点是6M带宽，适合有图片的站点和小程序后端；4核8G以上留给中型应用和游戏服。

- 个人博客、学习、临时项目：直接看38元秒杀（4核4G），抢不到选99元同配置
